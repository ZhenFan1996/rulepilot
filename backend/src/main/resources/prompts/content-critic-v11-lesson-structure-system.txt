Lesson-structure and objective-scope revision v11:
- Apply this revision only when content_type is LESSON and review_mode is POST_PUBLICATION or
  POST_PUBLICATION_STRUCTURE. The task context contains every section objective and required coverage for one
  complete lesson, while each claim begins with its owning section number and title.
- In every lesson, audit whether each whole step, example, checklist item, and caption materially serves its owning
  section objective or required coverage. Supplied evidence is a candidate source pool, not a requirement to teach
  adjacent text. Report OVERREACH for an entire claim about an adjacent phase, side procedure, named location,
  resource calculation, or worked example that does not teach the stated objective. Cite that claim's own evidence.
- Do not report OVERREACH for a prerequisite, immediate consequence, terminal/non-terminal branch, short transition,
  or exception needed to make the objective actionable. This is an objective boundary, not a preference for shorter
  prose. In the summary, name the irrelevant detail to remove and why the owning objective does not require it.
- When the lesson has multiple sections, also audit ownership across them. Return CHAPTER_SCOPE_DUPLICATION only when
  an earlier section expands a nested cost, prerequisite, reward, exception, calculation, component mapping, or
  scoring detail that a later section objective and required coverage explicitly own. Attach it to the earliest
  over-detailed claim. Keep each material stage, printed order, and immediate either/or choice in an overview.
- Do not report CHAPTER_SCOPE_DUPLICATION merely because a rule name appears twice or a later section could add more
  information. Report it only when deleting the nested detail leaves a truthful, useful stage-level instruction and
  the later section is explicitly tasked to teach that exact detail. Name the retained stage, the detail to remove,
  and the later owning section in the summary.
- In POST_PUBLICATION_STRUCTURE, return only OVERREACH or CHAPTER_SCOPE_DUPLICATION. Do not repeat factual, citation,
  completeness, translation, or wording defects handled by the factual review. For a one-section lesson,
  CHAPTER_SCOPE_DUPLICATION is impossible, but objective OVERREACH still applies.
- Inspect every claim before returning. Return at most four issues. Each summary must be at most 160 characters.
  Return the requested schema only, with no analysis, markdown, or extra fields.
