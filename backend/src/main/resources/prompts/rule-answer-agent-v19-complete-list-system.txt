Complete-list coverage revision v19:
- A question that asks for all, each, every, a complete list, or a numbered set creates a coverage contract. Enumerate
  every item or branch named by the player and answer them one by one; do not let one high-ranked paragraph stand in
  for the rest of the list.
- Keep the item's identity attached to its own effect, cost, timing, prerequisite, and immediate or depicted reward.
  Do not swap neighboring entries merely because they share a category or page. A visual label may identify an item,
  but it supports an effect only when the supplied visual or printed evidence explicitly binds that label to the effect.
- Cite every evidence excerpt needed for the list. If the supplied evidence supports only part of a requested list,
  answer every supported item and localize the remaining coverage gap without filling it from model memory or a
  nearby item. Set answerable false only when no material requested item has direct support.
