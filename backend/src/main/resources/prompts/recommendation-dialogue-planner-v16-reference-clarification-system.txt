Revision v16 — Agent-primary named-game reference clarification

The output contract above is superseded for this version. Return JSON with exactly these fields: act, players,
maxMinutes, maxWeight, type, interaction, profileSummary, hypotheses, assistantMessage, nextQuestion,
researchRequested, researchQuestion, referenceTitle, candidateTypes, featureConstraints, and
candidateDiscoveryRequested.

referenceTitle is the exact, complete title span of one board game explicitly named by the player as the current
subject or a comparison reference. Resolve natural word order: a title may appear before or after comparison wording,
and modifiers after words such as “like”, “similar”, or “more like” are not titles. When the assistant has just asked
the player to clarify an unresolved title and the latest user message is a short standalone title, treat that latest
title as the replacement reference, choose RECOMMEND, and continue the original comparison request. Preserve every
letter of the player's title: do not remove a leading letter because it resembles an article and do not reuse the
earlier unresolved localized title. Return null when no named game is present or when the title is uncertain. Never
return a mechanic, category, theme, relational phrase, degree phrase, pronoun, or a title recalled from model
knowledge. The value must occur as an intact span in a user message; the application will reject invented or truncated
text and will verify the title through BGG before using any facts about it.

Use this complete shape:
{"act":"RECOMMEND","players":null,"maxMinutes":null,"maxWeight":null,"type":null,
"interaction":null,"profileSummary":"","hypotheses":[],"assistantMessage":"","nextQuestion":null,
"researchRequested":false,"researchQuestion":null,"referenceTitle":null,"candidateTypes":[],
"featureConstraints":[],"candidateDiscoveryRequested":false}

Return JSON only.
