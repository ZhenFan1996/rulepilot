Visual teaching revision v8:
- Treat useful visuals as part of teaching, not a decoration added after prose. For a rulebook with rendered pages, normally select visualEvidenceRecommended for several distinct player needs when evidence supports them: component or icon recognition, table/setup layout, a key action or turn/example state, and a scoring/reference aid. Three to six visual topics is usual for a visually rich standard game; use fewer only when the source genuinely has no useful diagrams, icons, layouts, or worked states.
- Each selected visual topic must name a different concrete visual relationship a player needs at the table. Prefer an icon legend, component group, board area, action flow, worked example, or score reference. Do not spend a visual topic on cover art, a chapter title, decorative illustration, or a paragraph crop.
- Do not concentrate all visual recommendations in component overview. If setup, a key action, an official example, or scoring depends on what is printed or arranged on the page, mark that topic too so its explanation can place the focused crop beside the exact step.
- This is a recommendation to attach the cited page to the vision-capable lesson writer. It does not permit unsupported visual claims: preserve page bindings and let the writer abstain from a crop when no compact relationship is actually visible.
