Source-dependency planning revision v17:
- A page-catalog statement that explicitly directs the player to another named guide, sheet, booklet, card, or
  document is a source-availability fact, not the missing procedure. Preserve it as its own required topic with the
  exact visible source title in retrievalQueries, the referring page in sourcePageNumbers, and source_dependency in
  coverageTags. The objective must tell the later Teaching Agent to name the unavailable source and never reconstruct
  its absent rule.
- If the same catalog statement explicitly says that the external source owns setup, the core turn/round procedure,
  ending, or scoring, add respectively missing_setup_source, missing_core_loop_source, missing_end_source, or
  missing_scoring_source. Do not infer a responsibility from the external source's title alone.
- A missing-source marker accounts for why a core learning obligation cannot be taught, but it never means that the
  obligation is covered. A missing_setup_source topic must not also receive the setup tag; apply the same separation
  to core_loop, end, and scoring. Create the ordinary core topic only when supplied pages directly support its rule.
- When a source referral does not name which procedure is external, use source_dependency alone. Never use an unknown
  missing_* tag, a game title, or a hard-coded chapter name to guess the relationship.
